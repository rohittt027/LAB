Day 1 - 2
Intro to Programming

Definition

A Programming Language is a formal language used to communicate with computers.

Types of Languages

  • High-Level Language: Software oriented. Used in Web, App, ML, Data Science. Examples: C++, Java, Python.
  • Low-Level Language: Hardware oriented. Used in keyboards, washing machines. Examples: Machine & Assembly lang.

Applications

  • Web Apps: Run in browsers (Chrome/Safari). Need Internet. Platform Independent.
  • Mobile Apps:
    a) Web: URL based.
    b) Native: Platform dependent (Playstore).
    c) Hybrid: Both (WhatsApp, FB).
  • Desktop Apps: Offline usage. (Excel, MS Word).

Web Architecture & Python

Website Parts

  • Frontend: User visible part. (UI). Uses: HTML, CSS, JS, React.
  • Backend: Server-side logic. Uses: Python, Node.js, PHP.
  • Database: Structured data storage. Uses: SQL (MySQL, PgSQL).

Python: The 5W's

Python is a High-level Interpreted language.

  • Who: Guido Van Rossum
  • When: Feb 1991
  • Where: Netherlands
  • Why: Easy to read, huge ecosystem.
Common Mistake:
Thinking Python is compiled. It is Interpreted (line-by-line)!
Comparison Snippets

Python:

Debugging Flow

Find Error ➔ Fix ➔ Run

Language Types

  • Interpreted: Line by line. Easy to debug. (Python).
  • Compiled: Entire code at once. Fast. (Java/C++).
  • Hybrid: Both. (JavaScript).
Day 5 - 8
Variables & Operators

Variables

A container to store values. (Like a Water Bottle).

Rules for Variables:

  • Must start with Letter or Underscore (_).
  • No spaces or special chars (!, @, #).
  • Case-Sensitive (name != NAME).
  • Keywords cannot be used.

Arithmetic Operators

  • / Division (Float)
  • // Floor Division (Int)
  • % Modulus (Remainder)
  • ** Exponent (Power)

Logic Gates (AND)

ABY
000
111

Logical Operators

  • AND: True if both true.
  • OR: True if at least one true.
  • NOT: Reverse the state.

Bitwise Basics

Performs operations on Binary numbers.

Ex: 5 & 6 → Binary 0101 & 0110 = 0100 (which is 4).

Exam Tip:
Input() function always returns a STRING by default. Use int() to convert!
Day 11 - 17
Strings & Conditionals

Strings & Slicing

Sequence of characters. Slicing formula: string[start : end : gap]

Note: Ending point is ALWAYS excluded!

lang = "Programming"
print(lang[0:4]) # Output: Prog

String Methods

  • len(): Find length.
  • strip(): Remove extra spaces.
  • replace(): Swap substrings.

Lists

Store multiple data types: [1, "Ravi", True]

  • Positive Index: Starts at 0.
  • Negative Index: Starts at -1 (from right).

Conditional Statements

Uses if and else.

Indentation is Backbone!

Python uses Colon (:) to define the body.

if a > b:
    print("A is greater")
else:
    print("B is greater")
Memory Trick:
Gap = n-1.
If gap = 2, skip 1 element.
If gap = 3, skip 2 elements.
